## 产品介绍

**Reposilite** 是面向 JVM 生态 Maven 构件的轻量级、自托管仓库管理器，支持构件托管、代理仓库、访问 Token 和 Web 控制台。

## 主要功能

- **仓库托管**：提供 releases 和 snapshots 仓库，用于存放和分发 Maven 构件。
- **远程代理**：代理 Maven Central 等远程仓库，缓存依赖以加速构建。
- **访问控制**：基于 Token 的权限管理，可细粒度控制浏览、发布和删除权限。
- **Web 控制台**：通过浏览器管理仓库、Token 并查看统计信息。
- **存储扩展**：支持本地文件系统与 S3 兼容对象存储，提供插件系统扩展功能。
